# Fyxtez Website

Personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Requirements

- Node.js 22.13 or newer
- npm

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm run start
```

The project is a self-contained, standard Next.js application. No external
platform configuration or database is required.
